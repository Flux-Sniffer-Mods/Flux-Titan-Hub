Flux Keyboard 0.93 · the APK is under **Assets** below.

## New
- **Background picture** behind the keys: drag, zoom and rotate it on a preview, with key colours and opacity to match.
- **Recommended settings** offered after updates, listing each change from yours to the recommended one.
- **Ctrl + Shift + D** adds the last word to the dictionary.
- A password you just copied is offered in password fields as ⎘ ••••••••.

## Improved
- **Titan 2 Elite**: straight LEDs by default, or contoured LEDs on every page with corner buttons shaped to the calibrated display corners; straight corner buttons reach down and out to the edge on every page.
- **Trackpad**: sliding from one key to the next picks a suggestion; one-choice swipe-to-delete; sensitivity sliders beside the suggestions; a shortcut to the phone's Scroll assistant.
- **Themes**: the keyboard switches between Pastiera's Classic Midnight and Cloud themes with the system's dark mode.
- **Settings**: recommended settings from the Titan 2 Elite's own setup, clearer punctuation spacing, restricted-settings guide, tidier pages, a rewritten tutorial, and setting links (hold a setting) that open it in the app.
- **Defaults**: an everyday menu bar, Symbols as the only SYM layer, Termux:X11 and Niagara keep the keyboard hidden, no microphone in terminals, and new LED colours.

## Fixed
- No automatic space after punctuation in email, sign-in, web address and password fields.
- Updates install after allowing installs, and never miss a release.
- Automatic Shift in new Keep notes and chat boxes; a locked Ctrl lets go after a shortcut; Shift + Backspace deletes forwards on the Titan.
- Spell check understands apostrophes (couldn't, I'm); one-time codes are picked more accurately.
- Backups include the display corner calibration; copied passwords stay out of the clipboard history.

## From Pastiera
- Up to date with **Pastiera 0.86**, its final feature release, including contour LEDs, SYM shown while held and a keyboard-coloured navigation bar.
